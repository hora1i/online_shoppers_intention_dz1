# Домашнее задание 1: Online Shoppers Purchasing Intention

**Какой датасет выбрали и почему**
Я взял этот датасет потому что у него есть явный дисбаланс классов(15% покупок), комбинация числовых и категориальных признаков, что поможет протестировать разные методы

**Список гипотез (до начала работы)**
1. Использование параметра class_weight='balanced повысит полноту (Recall) логистической регрессии из-за сильного дисбаланса классов.
2. Отбор признаков (L1) обнулит часть колонок без критического падения F1-score.
3. GridSearch предотвратит переобучение дерева решений, ограничив его глубину.
4. Масштабирование (StandardScaler) ускорит работу логистической регрессии.
5. Случайный лес (RandomForest) покажет метрику F1 выше, чем базовое дерево.

**Краткие результаты**
Все гипотезы подтвердились экспериментально. Масштабирование стабилизировало сходимость логистической регрессии, а балансировка классов позволила находить редких покупателей. Ограничение `max_depth` алгоритмом GridSearch успешно устранило переобучение базового дерева решений.
